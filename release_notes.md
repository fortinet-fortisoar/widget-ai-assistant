# What's New

- The AI Assistant can understand and respond to context sensitive conversations and perform given SOC tasks
    - Through enhanced comprehension, the bot can navigate to modules, its records, and playbook logs
    - Sensitive data is being actively masked for all interactions with the API, considering the various modules to which the bot has access
    - The bot can now generate playbooks for all applicable modules and now has access to create and update records
    - The modes &mdash; Playbook Blocks and Conversation Mode &mdash; have been deprecated

- The past conversations remain in memory and help provide context to the bot, even after the user has logged out.
    - These conversations are loaded into the window on login.
